AV1 / AV2 资料学习记录
日期：2026-10-16

学习范围：40 份 PDF，39 份独立内容，1217 页；20 页扫描认证资料已做 OCR。
全部 PDF 建立逐页检索；重点技术章节和部分关键表格已核对。索引不等于所有字段已完成解码验证。
四个 STP 机械模型仅建立清单，不作为故障日志解析规范。

最重要的适用边界：
1. 460 历史样本 MFG0 三个配置区都能读到 SAS5032W / 460-16e / PCIe Gen5，后续按 AV2 IOC 范围选择规则。
2. AV1/AV2、RoC/IOC、运行模式、FW/CLI/StoreLib 版本要联合确定；压缩包名不是适用性依据。
3. 物理卡、PF/IOC、OS 控制器、管理视图、OS 可见设备分别处理。
4. DSN（物理槽位号）、SlotIndex、CEI 和 Persistent ID 不可直接等同。
5. StoreLib、传输、MPI、DCMD、SCSI/NVMe 的错误码，以及 Boot/PEL/FaultCode 均需命名空间。

下一轮解析改进优先级：
1. Identify SAS5032W/AV2 and RoC versus IOC before applying AV1 profiles/cache assumptions
2. Separate physical card / Supervisor / Non-supervisor / OS controller visibility
3. Keep SlotIndex/CEI/DSN distinct; bound existing range-slot conflict inference
4. Parse status layers and population/length validity before numeric decoding
5. Keep event namespaces, number bases and boot sequences explicit

已提炼的规则（每条均为学习候选，需另行实现/验证）：

GEN-01 [generation]
控制器芯片、RoC/IOC、板卡和运行模式共同选择规则；AV1/AV2 压缩包名不是适用性判断。
工具含义：给 operating_mode 和后续字段解码增加代际适用条件。
出处：AV2-038 PDF页 4,5,6；AV1-021 PDF页 7,8
限制：Validate against captured controller identity, firmware and exact raw fields before enabling a deterministic rule.

GEN-02 [AV2 RoC]
AV2 RAID 使用集成缓存；不能沿用 AV1 RAID 必须有外置 DDR 的硬件预期。
工具含义：缺少外置 DDR 不能直接生成 AV2 硬件故障。
出处：AV2-038 PDF页 5；AV2-030 PDF页 1
限制：Validate against captured controller identity, firmware and exact raw fields before enabling a deterministic rule.

GEN-03 [AV2 RoC versus IOC]
AV2 RoC 的 SSD/介质限制不能套到 SAS5032W IOC/HBA；文档中 IOC 支持 SAS/SATA HDD。
工具含义：按芯片角色检查支持介质，避免把 HBA 上的 SATA/HDD 判为不支持。
出处：AV2-038 PDF页 6,13
限制：Validate against captured controller identity, firmware and exact raw fields before enabling a deterministic rule.

GEN-04 [profile]
AV1 eHBA 的 IT/FeatureHBA/9620-EVP profile 表不是所有 MPI3 或 AV2 产品的通用定义。
工具含义：先识别芯片代际，再以显式运行模式核对 profile。
出处：AV1-021 PDF页 7,8；AV2-038 PDF页 5
限制：Validate against captured controller identity, firmware and exact raw fields before enabling a deterministic rule.

MPF-01 [AV2]
多个 PCIe/MPI/IOC 实例可能属于一张物理卡；使用 Supervisor、FunctionID、序列号和映射关系关联。
工具含义：物理卡、PF、OS 控制器实例分层，避免重复计数。
出处：AV2-038 PDF页 14；AV2-036 PDF页 9,10
限制：Validate against captured controller identity, firmware and exact raw fields before enabling a deterministic rule.

MPF-02 [AV2]

工具含义：按 PF 角色解释缺少管理数据；不能把桥设备统计为存储卡。
出处：AV2-038 PDF页 8；AV2-036 PDF页 9

MPF-03 [AV2]

SLOT-01 [enclosure topology]
Device Slot Number、SlotIndex 和 CEI 不是同一字段。非连续 DSN 示例中 DSN=16 对应 Persistent ID=X+4，而不是 X+16。
工具含义：现有 range_slot=first_slot+(pid-first_id) 只能作有条件的索引候选；不能普遍与物理 slotNumber 比较后判冲突。
出处：AV1-023 PDF页 5,6
限制：2021 AV1 规范与 2025 概览需按实际拓扑/固件核对；优先保留显式槽位证据。

SLOT-02 [AV1 enclosure]
相同 ELI 的多个 expander 被当作同一 enclosure；多路径必须报告相同 ELI。
工具含义：将 expander、路径、enclosure、物理盘分开，避免多路径重复盘和重复机箱。

SLOT-03 [AV1 enclosure]

工具含义：为拓扑/发现错误提供具体补证方向；单个错误不直接证明背板或线缆损坏。
